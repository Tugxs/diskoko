# استيراد قالب سيرفر — الإصدار الأول

ملف JSON بصيغة `diskoko-server-template` وإصدار `1`، مع `definition` مطابق لمحرر القوالب الجاهزة. يوفر المحرر زر «تحميل ملف القالب» لإنتاج الملف.

يشمل البنية والميزات المحفوظة والمدعومة: الرتب وأنواع صلاحياتها، التصنيفات والقنوات النصية والصوتية وترتيبها ووصولها، الترحيب، التذاكر، السجل، بطاقات البداية والميزات التفاعلية للقالب. يعاد اختيار بوت التنفيذ للمقصد؛ لا ينقل الملف رمز بوت أو حسابًا أو أعضاء أو محادثات.

الاستيراد لا يرسل شيئًا إلى Discord. يمر أولًا بالتحقق الخادمي ثم محرر المسودة والمعاينة ومراجعة التنفيذ. يستخدم نفس حدود الاستخدام وقفل السيرفر وحفظ خطوات التنفيذ ومنع إعادة الخطوات المكتملة التي تستخدمها القوالب الجاهزة.

حاليًا لا يقبل رابط دعوة أو ملفًا عشوائيًا من موقع آخر أو قالب Discord الخام. النسخة التالية تحتاج محولًا محددًا لكل صيغة، مع بيان الفروق؛ لا يجوز تحويل الصلاحيات أو إسقاط الميزات بصمت. حجم الملف الأقصى 5 ميجابايت. قواعد السجل العابرة للسيرفرات مرفوضة حتى تُستبدل بمعرّفات داخل القالب.

القوالب المستوردة والمسودات محفوظة في جلسة المتصفح بحسب الحساب والسيرفر، وليست مكتبة سحابية دائمة. عمليات التنفيذ والمراجعات محفوظة خادميًا.
