# متابعة توسعة ديسكوكو AI

## حدود هذا الإصدار الجاري

التجارب داخل Discord يتولاها العميل. الفحوصات المحلية لا تعني إثبات تشغيل جميع الوظائف في السيرفر. لا يُضاف مسار تنفيذي جديد لمجرد إضافة رسالة إلى المكتبة أو تنزيل مستودع.

## ما تم تجهيزه محليًا

- فحص توافق جميع رسائل المكتبة الحالية مع عقود المسودات المسجلة ووجود ملفات التنفيذ ونطاق المستخدم والسيرفر والبوت.
- تصنيف المدخل غير المسجل كقدرة تحتاج تطويرًا بدل عرضه كمسودة تنفيذية جاهزة.
- تحديث عقود وحدات النماذج لتصف إرشادات الحقول وحدود طولها وأزرار الروابط ومكان الصورة كإعدادات اختيارية حقيقية.
- وصف عدد المقاعد وموعد التسجيل في عقد الفعاليات.
- رفض إجابة النموذج التي تتجاوز الحدود بدل قصّها وحفظ نص ناقص.
- حساب صلاحيات البوت داخل قناة اللوحة وقناة المراجعة باستخدام ترتيب استثناءات Discord؛ وفحص إرفاق الملفات للتصميم المصور.

## أعمال التوسعة المطلوبة بعد هذه الأسس

| المجموعة | العمل المطلوب | شرط الاعتماد |
|---|---|---|
| النماذج المرنة | حقول إضافية وأنواع وإلزام واختيار وترتيب، مع تخزين إجابات بإصدار محدد | محرر ومعاينة وتحقيق خادمي ومعالج إرسال ومراجعة يدعمان نفس المخطط |
| الرتب | طلب موافقة ومنح بعد القبول، إلى جانب الاهتمامات الحالية | منع منح صلاحيات مرتفعة، وإعادة فحص هرمية الرتب عند الضغط |
| الدعم | أقسام وأسئلة افتتاحية وتوجيه واستلام وتقييم | ربط كامل بمعالجات التذاكر الحالية وعزل القناة |
| الفعاليات | قائمة انتظار وتذكيرات وملخص حضور | وظائف مجدولة متينة ومنع التسجيل المكرر وإعادة التشغيل الآمنة |
| المهام | مسؤول وموعد وحالة مستقلة | صلاحية فريق ومراجعة كل انتقال وتخزين حقول منظمة |
| الإعلانات | ربط مسودة بالمجدول وتعديل وإلغاء | تحديد المنطقة الزمنية ومنع تنفيذ النسخة القديمة |
| المعلومات | مصادر بيانات فعلية وتحديث اللوحة | موصل مسجل وصلاحيات مصدر ومعدل تحديث محدود |
| الأتمتة | أحداث وشروط وإجراءات معتمدة | حدود حلقات وتكرار وسجل نتيجة وعزل وفشل يحتاج مراجعة |
| التكاملات | دراسة الموسيقى والمصادر الخارجية لكل مزود | تشغيل موثق ومصدر مسموح وضوابط تكلفة وتوفر؛ لا وعود من المعرفة وحدها |

## معايير التوافق الدائم

كل وظيفة جديدة تحتاج عقد بيانات، محررًا، معاينة قابلة للتطبيق، مراجعة خادمية، منفذًا، نتيجة تشغيل وتعديلًا بعد النشر. تُضاف اختبارات العقد والعزل والصلاحيات ومنع التكرار إلى الفحص العام. تبقى مراجعة العميل والتأكيد النهائي قبل أي نشر، وتبقى الأعطال الغامضة بحاجة مراجعة الحالة قبل إعادة التنفيذ.

المكتبة الحالية متوافقة على مستوى العقود المسجلة؛ هذا لا يثبت اكتمال تجربة المحادثة أو التشغيل الفعلي لكل مدخل. تبقى هذه التجارب في قائمة قبول العميل.
