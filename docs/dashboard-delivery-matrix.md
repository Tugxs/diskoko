## حدود واضحة

- النسخة تحفظ بنية القنوات والرتب والقوالب المثبتة عبر المحرر. لا تنسخ المحادثات أو الأعضاء أو مفاتيح الخدمات أو اللوحات المستقلة. كل قالب ميزات يستعاد إلى محرر قابل للمراجعة، ولا يعاد نشره تلقائيًا.
- صلاحيات @everyone تبقى كما هي بموافقة منفصلة عند اختلافها؛ رتب التطبيقات لا تستنسخ، واستثناءات الأعضاء وأنواع القنوات غير المدعومة تُرفض بدل إسقاطها بصمت.
- تحديث قالب قديم لا يملك نسخة أساس يتطلب مقارنة يدوية؛ التحديث الآلي الآمن متاح للمراجعات الجديدة التي حفظت أساس المكتبة.
- المعاينة الخاصة تختبر الشكل فقط. قبول الأزرار والقوائم والصوت يتطلب اختبار Discord المشترك.
- التكرار اليومي/الأسبوعي بفواصل ثابتة؛ المنطقة الزمنية تطبق على إدخال الموعد وعرض التقويم. الانتقال الصيفي الغامض أو غير الموجود يرفض عند الإدخال؛ تثبيت ساعة محلية عبر انتقالات DST ليس محركًا مضافًا.
- قيود الفريق تقيد تنفيذ الأدوات؛ لا تتجاوز اشتراك العضو أو ملكية مساحته الخاصة، ولا تحول المنصة إلى حساب مشترك ببيانات العملاء.
- محركات Node/Python/Native تبقى مقفلة وقريبًا. لا يوجد هنا وعد بتنفيذها.
