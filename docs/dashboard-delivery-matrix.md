# تنفيذ تطوير لوحة العميل

مصدر البداية: main عند 88fd9ad، مع إعادة المزامنة قبل النشر. تطوير AI خارج هذا الفرع، واختبار Discord المشترك مؤجل لنهاية التسليم بطلب العميل.

| المجال | نطاق القبول | الوضع |
|---|---|---|
| نظرة عامة | جاهزية صلاحيات كل أداة، العمليات الجارية، اختيار المقاييس | الجاهزية والعمليات مضافة؛ تخصيص المقاييس باقٍ |
| تنبيهات | تجميع حسب المصدر، تأجيل، رابط إصلاح مع رقم متابعة | التجميع والتأجيل مضافان؛ روابط المعالجة التفصيلية باقية |
| القنوات والرتب | تعارض قبل التنفيذ، حذف مؤكد، إصدارات بنية ومقارنة استعادة | التعارض موجود؛ الحذف والبنية باقية |
| قوالب | مسودات سحابية ونسخ ومقارنة، تحديث وتحقق مراجع | المسودات والنسخ مضافة؛ تحديث وصحة المراجع باقيان |
| استيراد | مكتبة مسودات، تقرير توافق، صيغة رسمية مدعومة | المكتبة مضافة؛ تقرير التوافق والتحويل باقيان |
| لوحات | إدارة المنشور، فحص المراجع، قناة تجربة | إدارة المنشور أتت من تحديثات main؛ الفحص والتجربة باقيان |
| أوامر | مقارنة نسخة، حالات اختبار محفوظة، نجاح/تعطل | باقٍ |
| جدولة | تعديل/إيقاف/استكمال، منطقة زمنية، تقويم، سجل تكرار | مضافة؛ تكامل الواجهة والاختبار جارٍ |
| تحليلات | مقارنة وتصفية CSV، حذف مؤكد، بيان الاحتفاظ | مضافة |
| أمان | صلاحيات فعالة، معالجة نقص، قواعد فريق | الصلاحيات مضافة؛ قواعد الفريق باقية |
| سجل | بحث وتصفح، فاعل وبوت ونسخة، نتائج غير مؤكدة | البحث والتصفح مضافان؛ تفاصيل الربط باقية |
| إعدادات | منطقة زمنية، نسخ استعادة، الفريق، آخر مزامنة | المنطقة الزمنية مضافة؛ البقية باقية |

كل «مضافة» هنا تصف الكود المحلي، ولا تعني أنها منشورة أو مقبولة في Discord حتى يضاف دليل الاختبارات والنشر.
