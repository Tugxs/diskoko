# Nitro milestone artwork

The `nitro-ornate-*.png` files are the 512 × 512 transparent milestone icons uploaded by RavenaStar to Emoji.gg in February 2025. They match the eight badge shapes shown in Discord's [Evolving Nitro Badges](https://support.discord.com/hc/en-us/articles/29136565881623-Evolving-Nitro-Badges) help article.

Emoji.gg lists its Basic License as allowing use on Discord and other platforms where users are not charged for access to the emoji. These images are used only in Diskoko's free Discord response cards.

Sources: [Bronze](https://emoji.gg/emoji/22441-nitro-style-bronze), [Silver](https://emoji.gg/emoji/93723-nitro-style-silver), [Gold](https://emoji.gg/emoji/37805-nitro-style-gold), [Platinum](https://emoji.gg/emoji/29342-nitro-style-platinum), [Diamond](https://emoji.gg/emoji/70226-nitro-style-diamond), [Emerald](https://emoji.gg/emoji/12239-nitro-style-emerald), [Ruby](https://emoji.gg/emoji/12239-nitro-style-ruby), [Opal](https://emoji.gg/emoji/53164-nitro-style-opal).
