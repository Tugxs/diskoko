العودة إلى الأوامر

أوامرك، بطريقتك

اكتب JavaScript وراجع الكود ثم أكد التفعيل. يفحص النظام النسخة ويحفظها ويُفعّلها؛ حفظ المسودة يدويًا اختياري.

مثال قائمة تفاعلية

function handle(ctx) {
  if (ctx.event.action === "choose") {
    return { message: { content: "Selected: " + ctx.event.values[0] } };
  }
  return { message: {
    content: "Hello " + ctx.user.name,
    controls: [{ type: "select", action: "choose", options: [
      { label: "Support", value: "support" },
      { label: "Rules", value: "rules" }
    ] }]
  }};
}

البيانات المتاحة

ctx.user اسم المستخدم ومعرّفه، ctx.guild السيرفر، ctx.event نوع الحدث والإجراء والاختيارات والحقول، وctx.state بياناتك المحفوظة لهذا المستخدم والأمر فقط.

ما يمكنك بناؤه

رسائل وبطاقات وصور عبر HTTPS وأزرار وروابط وقوائم ونماذج. أرجع message أو modal ومعهما state اختياريًا.

الزر: {type:"button",label:"Open",action:"open",style:1}. الرابط: {type:"link",label:"Website",url:"https://example.com"}.

النموذج: {modal:{title:"Feedback",action:"submit",fields:[{id:"opinion",label:"Your feedback",paragraph:true}]}}. تجد الرد في ctx.event.fields.opinion.

حدود البيئة الخاصة

تدعم البيئة async وawait ومشاريع ES modules بحد 20 ملفًا و128 KB. لا تتاح ملفات الخادم أو توكنات البوت أو مكتبات Node. أدوات Discord وHTTPS متاحة عبر SDK بالصلاحيات المعلنة، وليست وصولًا مفتوحًا. الحالة 8 KB، وحتى 5 عناصر تفاعلية و3 بطاقات. الأزرار تخص المستخدم الذي فتح الأمر وتنتهي بعد 15 دقيقة.

الحفظ والنسخ

الحفظ لا يغير النسخة المفعّلة. جرّب النسخة ثم أكد التفعيل. استعد نسخة سابقة من سجل النسخ وراجعها قبل تفعيلها. يمكنك إيقاف الأمر أو تنزيل ملفه أو حذفه.

مساعد AI

اطلب بناء الكود أو شرحه أو إصلاحه. تحصل على مسودة للمراجعة؛ لا يحفظها المساعد ولا يفعّلها تلقائيًا. يحتاج عامل AI متصلًا وباقة مناسبة.

مساحة المطور

اختر مشروع متعدد الملفات، ثم اكتب ملف البداية وملفات التصميم والمكتبات. تحفظ جميع الملفات كنسخة واحدة؛ التعديل لا يغير الإصدار المنشور. يمكن رفع وتنزيل المشروع بصيغة JSON.

التخزين المشترك

استخدم storage.get وstorage.set وstorage.delete لحفظ بيانات تجمع مستخدمي هذا الأمر، مثل المشاركين والنقاط. التخزين خاص بالمشروع: 256 مفتاحًا و256 KB إجمالًا، و8 KB للقيمة.

أدوات Discord

استخدم discord.send وdiscord.addRole وdiscord.removeRole وdiscord.createChannel وdiscord.updateChannel. التنفيذ يفحص صلاحية العضو والبوت والسيرفر وترتيب الرتب. لا يسمح بمنح رتبة Administrator أو تجاوز صلاحيات العضو.

الاتصال والمفاتيح

أعلن صلاحية http والنطاقات في origins، ثم استخدم http.request. يدعم GET وPOST عبر HTTPS، ويحجب الشبكات الداخلية والتحويلات. احفظ المفتاح مشفّرًا من سجل المشروع، وحدد credential باسم المفتاح؛ لا تضع التوكن داخل الكود.

الجدولة

أعلن schedule ثم استخدم schedule.after بالثواني والقناة والإجراء والبيانات. يصل الحدث لاحقًا بنوع schedule. المدى 10 ثوانٍ إلى 7 أيام، وحد 20 مهمة معلقة و100 مهمة يوميًا لكل مشروع. تغيير النسخة أو إيقاف المشروع يلغي المهام المعلقة.

المعاينة والسجل

التخزين في المعاينة مؤقت والعمليات الخارجية محاكاة فقط. راجع console.log وسجل العمليات والمهام. العمليات الخارجية ليست معاملة واحدة قابلة للتراجع؛ عند نتيجة غير مؤكدة راجع السجل قبل إعادة المحاولة.

الحزم والحدود

يمكن إضافة مكتبات JavaScript متوافقة كملفات داخل المشروع واستيرادها. تثبيت npm وتشغيل مشاريع Node أو مكتبات native أو Python غير مدعوم في هذه البيئة. المهام المجدولة تنشر رسائل وبطاقات؛ النماذج تتطلب تفاعل مستخدم، ولا يمكن فتحها بعد تأجيل رد Discord.
