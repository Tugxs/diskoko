العودة إلى الأوامر

أوامرك، بطريقتك

اكتب JavaScript، جرّبه واحفظه في مساحة خاصة بحسابك وسيرفرك وبوتك. التفعيل خطوة منفصلة بعد مراجعتك.

مثال قائمة تفاعلية

function handle(ctx) {
  if (ctx.event.action === "choose") {
    return { message: { content: "Selected: " + ctx.event.values[0] } };
  }
  return { message: {
    content: "Hello " + ctx.user.name,
    controls: [{ type: "select", action: "choose", options: [
      { label: "Support", value: "support" },
      { label: "Rules", value: "rules" }
    ] }]
  }};
}

البيانات المتاحة

ctx.user اسم المستخدم ومعرّفه، ctx.guild السيرفر، ctx.event نوع الحدث والإجراء والاختيارات والحقول، وctx.state بياناتك المحفوظة لهذا المستخدم والأمر فقط.

ما يمكنك بناؤه

رسائل وبطاقات وصور عبر HTTPS وأزرار وروابط وقوائم ونماذج. أرجع message أو modal ومعهما state اختياريًا.

الزر: {type:"button",label:"Open",action:"open",style:1}. الرابط: {type:"link",label:"Website",url:"https://example.com"}.

النموذج: {modal:{title:"Feedback",action:"submit",fields:[{id:"opinion",label:"Your feedback",paragraph:true}]}}. تجد الرد في ctx.event.fields.opinion.

حدود البيئة الخاصة

الدالة متزامنة. لا تتاح ملفات البوت أو توكناته أو الإنترنت أو مكتبات Node. لا توجد إدارة رتب وقنوات في هذا الإصدار. الكود 24 KB والحالة 8 KB، وحتى 5 عناصر تفاعلية و3 بطاقات. الأزرار تخص المستخدم الذي فتح الأمر وتنتهي بعد 15 دقيقة.

الحفظ والنسخ

الحفظ لا يغير النسخة المفعّلة. جرّب النسخة ثم أكد التفعيل. استعد نسخة سابقة من سجل النسخ وراجعها قبل تفعيلها. يمكنك إيقاف الأمر أو تنزيل ملفه أو حذفه.

مساعد AI

اطلب بناء الكود أو شرحه أو إصلاحه. تحصل على مسودة للمراجعة؛ لا يحفظها المساعد ولا يفعّلها تلقائيًا. يحتاج عامل AI متصلًا وباقة مناسبة.
